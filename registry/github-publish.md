# 技能档案：github-publish

- **name**：github-publish
- **description**：把本地 git 项目推到 GitHub（建仓库 / 设远程 / 推送 / 验证）
- **能力标签**：代码、执行
- **用途标签**：CI/CD
- **领域标签**：Development / DevOps
- **动作角色**：执行
- **职业标签**：（可选）
- **负触发词**：只想写 README / 文案、只想生成 token 时别用
- **验收标准**：git ls-remote 有 main 分支 + 浏览器能看到文件
- **权限需求**：网络、GitHub 账号、写本地文件
- **环境要求**：需要联网 + git
- **来源 + 版本**：自建 v0.1（沉淀自 2026-08-14 首次上传的经验）
- **户口**：global
- **依赖技能**：无
- **Gotchas**：账号以浏览器实际为准（lib420888-gif）；仓库名大小写敏感；push 要登录/token；沙箱要批准联网

> 信任度 / 次数 / 上次使用：见 memory/usage-log.md
